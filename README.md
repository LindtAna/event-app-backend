Full-Stack-System zur Erstellung und Verwaltung von Events. 

Das Projekt kombiniert ein performantes Go-Backend mit einer modernen React-Frontend-Architektur und bietet Funktionen wie Authentifizierung, Event-Suche, Kategorisierung.

### Tech Stack:
* **Backend:** Go (Golang), Gin Framework, SQLite, SQL Migrations (`golang-migrate`), Air (Hot Reload).
* **Frontend:** React, Tailwind CSS, Shadcn UI, Formularverarbeitung & Validierung (Zod / React Hook Form), Clerk (Auth).
